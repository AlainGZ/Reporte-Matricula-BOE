# Logo institucional

Coloca aquí el logo oficial de UNIMINUTO con este nombre exacto:

```
assets/logo_uniminuto.png
```

Requisitos del archivo:
- Formato **PNG** con fondo transparente (Tk lo lee de forma nativa, sin
  dependencias adicionales).
- Alto recomendado: **120 px o más** (la interfaz lo reduce automáticamente a
  ~56 px de alto en la cabecera; si lo subes muy pequeño se verá pixelado).

Si el archivo no está presente, la aplicación funciona igual: la cabecera se
muestra sin logo, sin ningún error.

Este archivo no se incluye en el repositorio porque no tengo el activo oficial
del área de comunicaciones — agrégalo tú (o quien tenga acceso al kit de
marca) y no hace falta tocar ningún código.
